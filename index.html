Présentation du logiciel Pilote

Un seul logiciel pour les mails, les devis, les factures, le stock, l’agenda, la banque et la comptabilité de votre groupe.

Aujourd’hui, une partie des informations est dans les mails.

Une autre partie est dans Word et Excel.

Le reste est dans plusieurs logiciels.

Pour retrouver un devis, il faut chercher partout.

Avec Pilote, tout est dans le même logiciel.

La facture électronique
devient obligatoire
